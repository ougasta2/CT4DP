# DK1の需要予測・価格予測：数式と実装

## 評価条件

予測対象はDK1の翌日各時間の卸電力価格。通常の実験は供給日前日10:00、
EXAA実験は前日11:00（ともにコペンハーゲン時間）を予測時点とし、12:00の
市場結合入札より前の情報だけを使う設計。実際の価格が負・ゼロにもなりうる。

主指標は `|y - y_hat| <= 0.05 |y|` を満たす割合で、`|y| >= 20 EUR/MWh`
の時間だけを分母に含める。MAEは低価格・負価格を含む全時間で測る。
2025年10月以降の15分価格は4区間の平均を1時間価格として扱う。

## 需要予測：論文の数式

Ziel & Liu, *Lasso estimation for GEFCom2014 probabilistic electric load
forecasting*, International Journal of Forecasting (2016) の式(10)・(11)を参照：
[論文](https://doi.org/10.1016/j.ijforecast.2016.01.001)。
需要の基準式は、月・曜日・時刻のカテゴリ効果と曜日×時刻の交互作用、
および気温の1〜3次の項とそれぞれの月・時刻との交互作用で表される。

```text
L_t = b0 + b_M[M_t] + b_W[W_t] + b_H[H_t] + b_WH[W_t,H_t]
    + Σ(k=1..3) { a_k T_t^k + a_M[k,M_t] T_t^k
                    + a_H[k,H_t] T_t^k } + error_t
```

`L_t`は需要、`T_t`は当該時間の気温。カテゴリはone-hotで表現する。
実装 [train_dk1_vanilla_load.py](../scripts/train_dk1_vanilla_load.py)は、
この説明変数を使いつつ、計算の安定性のため小さいRidge罰則を加え、
予報気温を使い、月次で過去2年を使って再学習する。論文の確率シナリオ生成を
再現したものではなく、正則化や天候入力を変更した点予測の適用である。

別の候補として、過去の需要曲線、予報天候、曜日・季節から24時間分を同時予測
するRidgeを実装した。確定値を用いる版は `L_(d-14), L_(d-21), L_(d-28)`、
ENTSO-EのH+1需要値を使う版は `L_(d-2), L_(d-7), L_(d-14)` を入力する。
各時点の需要予測は、予測対象月より前のデータで推定したモデルから生成する。
未来の需要実績を価格モデルへ入れていない。

## 価格予測：論文の数式と拡張

LagoらのLEARベンチマークでは、各時刻の価格を過去の価格曲線と外部予測から
線形に予測し、係数の絶対値に罰則をかけて推定する。
[論文](https://doi.org/10.1016/j.apenergy.2021.116983) の式を基に：

```text
p_hat[d,h] = b_h + Σ_j beta[h,j] X[d,j]
beta_hat_h = argmin_beta { (1/2n) Σ_d (p[d,h] - b_h - beta_h·X[d])²
                            + lambda ||beta_h||_1 }
```

`X`には過去価格、事前予測した需要、予報天候、遅行した燃料価格を含める。
[train_dk1_demand_price.py](../scripts/train_dk1_demand_price.py)はこの考え方の
適用であり、論文の公式実装と同一ではない。固定lambda、独自の入力、月次更新を
使う。時系列の各学習窓で標準化を学習し、需要の入力にも過去データだけから
生成した時間外予測を使う。

さらに、LEAR参考モデルの**学習に使われていない過去予測**を入力に含めた
勾配ブースティングを実装した。[train_dk1_nonlinear.py](../scripts/train_dk1_nonlinear.py)
で線形予測、過去価格、天候、需要予測を使い、時間ごとの価格を予測する。
誤差のみを予測する別モデルも試している。過去の予測誤差で学習するため、
学習データに対する見かけ上の当てはまりを補正対象にしない。

## 入手した情報と評価上の区別

- ENTSO-Eの[需要予測規則](https://transparencyplatform.zendesk.com/hc/en-us/articles/16647979768084-Actual-Total-Load-Day-ahead-Per-Bidding-Zone-6-1-A-6-1-B)
  は原則として入札締切の2時間前までの公表と、その後の重要な変更時の更新を定める。
  取得済みの2021〜2025年の事後バックフィルには個別の当時の版がないため、
  現時点の値を10時に存在した値とみなさず、`tso_revised`として別評価する。
- 同資料はDK1・DK2の需要実績についてH+1までの公表・その後更新なしと記載。
  より短い過去需要を使うモデルにこの規則を適用するが、個々の履歴行の
  実際の公表時刻を確認したわけではない。
- 過去の気象予報・確定需要・燃料価格も、個々の公表時刻や改訂を監査できていない。
  したがって結果は正確なリアルタイム再現を保証しない。
- EXAAの10:15独立入札価格を使うときは**別の11:00予測**とし、10:00の
  ベンチマークと混同しない。11時に結果を取得できたことの個別記録は未確認。
  外部でEXAAと表示された候補データは、2024年1月の744時間すべてが12時の
  市場結合価格と一致したため、事前情報として除外した。
- 予測率50%は達成条件であり、現時点で達成していない。複数モデルを試し、
  評価年の選択結果、分母、誤差、実験回数やデータの欠損を明示する。
